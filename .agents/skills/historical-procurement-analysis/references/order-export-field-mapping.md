# 订单导出字段映射（真实样本验证）

本文件用于将企业订单导出类历史采购明细映射为 `historical-procurement-analysis` 的标准字段。

> 仅保存字段规则，不保存真实联系人、电话、地址、供应商名称等业务敏感数据。

## 1. 已验证的核心字段

| 原始字段 | 标准字段 | 主要用途 | 级别 |
|---|---|---|---|
| 订单编号 | `order_id` | 订单去重、采购频次 | 必要 |
| 订单创建日期 | `order_date` | 周期识别、同比/趋势 | 必要 |
| 物料编码 | `material_code` | SKU 稳定标识 | 必要 |
| 物料名称 | `material_name` | SKU 识别 | 必要 |
| 物料规格 | `specification` | SKU 可比性 | 必要 |
| 品牌 | `brand` | SKU 可比性 | 可选 |
| 数量 | `quantity` | 历史采购量基线 | 必要 |
| 单位 | `unit` | 单位一致性 | 必要 |
| 含税单价 | `tax_included_unit_price` | 历史价格基线 | 必要 |
| 不含税单价 | `pre_tax_unit_price` | 未税价格分析 | 可选 |
| 税率 | `tax_rate` | 税口径一致性 | 必要 |
| 含税总额 | `tax_included_amount` | 支出分析 | 必要 |
| 不含税总额 | `pre_tax_amount` | 支出分析 | 可选 |
| 供应商名称 | `supplier_name` | 历史合作/集中度 | 必要 |
| 供应商编码 | `supplier_code` | 供应商稳定标识 | 可选 |
| 收货地址 | `delivery_location` | 项目/区域汇总 | 必要 |
| 地址省份 | `province` | 区域分析 | 可选 |
| 地址城市 | `city` | 区域分析 | 可选 |
| 商品一级分类名称 | `category_level_1` | 品类分析 | 可选 |
| 商品二级分类名称 | `category_level_2` | 品类分析 | 可选 |

## 2. 周期识别规则

在任何同比或年度预测前，必须先读取 `订单创建日期` 的最早和最晚时间。

### 完整周期

只有当数据明确覆盖一个完整年度，或用户明确说明该文件为完整年度数据时，才可以把该年度作为年度采购基线。

### 部分周期

如果数据只覆盖若干周/月：

- 可以汇总采购量、金额、价格、SKU占比、项目分布；
- 可以形成短周期价格基线；
- 不得默认年化；
- 不得把部分周期采购量直接填成下一年度需求量；
- 若需要同比，应要求上一年度同口径、同周期数据。

## 3. SKU 聚合键

优先按：

`物料编码 + 物料规格 + 单位`

物料编码缺失时退化为：

`物料名称 + 品牌 + 物料规格 + 单位`

如果同一物料编码出现不同规格或不同单位，不得直接合并。

## 4. 金额字段规则

优先使用导出中的行级：

- `含税总额`
- `不含税总额`

并做校验：

`数量 × 含税单价 ≈ 含税总额`

存在小额四舍五入差异可以接受；明显不一致时标记 `amount_reconciliation_gap`。

## 5. 价格基线

如果同一可比 SKU 在历史周期内含税单价一致，可直接形成 `historical_price_baseline`。

如果价格发生变化，应同时输出：

- 最低价
- 最高价
- 加权平均价
- 最近成交价
- 变化幅度

不要只取简单平均掩盖数量差异。

## 6. 采购策略报告可复用分析

当数据支持时，可向 `strategy_report_handoff` 提供：

- 历史采购总额；
- 历史采购量；
- Top SKU 及采购额占比；
- 项目/区域采购分布；
- 供应商集中度；
- 历史价格基线；
- 月度/季度趋势；
- 异常采购记录；
- 数据周期完整性说明。

## 7. 数据隐私

真实订单导出通常包含：

- 联系人；
- 电话；
- 地址；
- 公司主体；
- 供应商名称；

这些字段只在当前采购分析任务中使用，不应作为公开示例上传到代码仓库。黄金案例应使用脱敏或模拟数据。
