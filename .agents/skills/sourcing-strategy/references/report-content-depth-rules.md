# 采购策略报告内容深度规则

本文件是 `sourcing-strategy` 的内容深度入口。

生成报告时必须同时遵循：

1. `report-content-quality-guide.md`
2. `template-v3-content-blueprint.md`
3. `procurement-plan-template-mapping.md`

## 核心 Contract

所有核心分析章节都使用：

`事实/数据 → 结构分析 → 影响判断 → 采购动作`

不得把“字段填了”视为“分析完成”。

### 支出分析

有数据时优先覆盖：

- 整体支出；
- 配送区域；
- 业务单元/军种/业态/项目；
- 订单金额段与订单碎片化；
- SKU/Pareto；
- 历史供方集中度；
- 历史价格；
- 免运额度/最低配送金额的事实依据。

每个可用维度应有数字化结构和结论；完整历史数据下至少形成3条数字证据发现和2条采购含义。

### 当地供应市场行情

必须组合：

- 企业内部可触达供方信号；
- 本地/目标区域供应格局；
- 当前品类成本驱动；
- 近期价格趋势或风险；
- 本地仓储配送/小额高频履约因素；
- 相关政策与标准；
- 至少3条与本项目直接关联的采购动作。

Web 可用且品类/区域明确时，应主动检索公开市场信息。`complete` 原则上至少需要3个相互独立的公开来源。

### 模板占位符

最终 DOCX 不得残留 `X / XX / X%`、历史案例供应商、历史案例金额/日期/人员或无来源成本比例。

用户提供的参考案例只用于学习分析深度和表达结构，不作为当前项目数据源。
