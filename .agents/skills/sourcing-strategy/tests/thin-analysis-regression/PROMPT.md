## Test objective

重点验证：

1. 支出分析不是模板标题或一句话；
2. 支出分析覆盖整体、区域、业务单元、订单金额段、SKU和历史供方等可用维度；
3. 订单金额结构必须被用于“免运额度/最低配送金额”分析，但不得擅自确定正式阈值；
4. 当地供应市场行情分析同时包含内部供应信号、外部市场研究、成本驱动、本地履约因素和采购策略影响；
5. 不保留 X / XX / X% 等模板占位符；
6. 不把公开市场发现的企业加入当前供应商短名单。
