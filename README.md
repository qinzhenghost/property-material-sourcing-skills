# Property Material Sourcing Skills — v0.3.0

物业物资类 AI 邀标寻源 Skill 库。

## 当前流程

`初版需求 → AI需求诊断/澄清 → 标准需求 → 官方供方库匹配 → 人工确认沟通供方 → 生成邀标邮件 + 最终需求清单 + 招标意向征集登记表`

## 当前 Skill

```text
skills/
├── material-requirement-analysis/

```

## 核心原则

1. V1 只做物业物资类采购，不做服务类。
2. 采购制度为邀标制。
3. 候选供方只能来自企业内部官方供方库或其明确授权的官方导出。
4. 公网搜索、行业榜单、搜索引擎、第三方企业库不得新增邀标候选供方。
5. AI 负责需求诊断、供方筛选解释、文件生成；采购员负责关键确认。
6. 最终邀标包固定由三个产出物组成：
   - 邀标/意向征集邮件正文；
   - 最终确认版需求清单；
   - 招标意向征集登记表。

完整项目文件由本仓库持续维护。
