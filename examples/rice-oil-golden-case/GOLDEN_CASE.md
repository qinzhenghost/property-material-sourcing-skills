# 黄金案例：重庆区域 2025-2026 年米面粮油物资框架

## 1. 样本来源

本案例基于用户提供的：

- `初版需求清单.xlsx`
- `最终版需求清单.xlsx`
- `招标价格对比表.xlsx`

目标不是把最终版机械当成“标准答案”，而是用真实版本演进验证 Skill 是否能发现采购需求从初版到可寻源/可报价状态之间的关键变化。

## 2. 初版观察

初版共 18 条物料记录，主要列包括：

- 序号
- 名称
- 单位
- 起订量
- 年度预计采购量
- 含税单价（空）
- 含税总价（空）
- C端参考价格（部分有值）

### 重要判断

`含税单价`、`含税总价` 是供方报价阶段待填写/计算字段，不应被当作采购需求缺口。

## 3. 初版高价值缺口

### 3.1 物料级

18 条物料均缺少明确品牌和规格/容量信息，无法保证不同供方按同一 SKU 口径报价。

重复名称包括：

- 特香低芥酸菜籽油（非转基因）：4 行
- 压榨本香菜籽油（非转基因）：2 行
- 纯香菜籽油（非转基因）：2 行
- AE营养多纯香菜籽油（非转基因）：2 行
- 玉米油黄金产地压榨一级食用油（非转基因）：2 行
- 黄金比例食用植物调和油（非转基因）：2 行

同名同单位重复出现，应触发隐藏维度检查。

“特香低芥酸菜籽油（非转基因）”的不同重复行还出现 57.7 与 44.74 两种 C 端参考价格，这可以作为“可能存在不同规格/容量”的证据，但不能直接推断具体规格。

### 3.2 项目级

初版未明确：

- 配送区域
- 报价是否含税/含运
- 预计采购量是否仅供参考
- 付款/账期
- 合作期限
- 评标价格口径
- 计划中选供应商数量

这些会影响供方适配性和报价可比性，应作为优先澄清项。

## 4. 最终版发生的关键变化

最终版仍为 18 条物料，但新增/明确了：

### 4.1 物料级字段

- 品牌
- 规格
- 未税单价（供方响应字段）
- 税率（供方响应字段）
- 备注

示例：

- 特香低芥酸菜籽油 → 金龙鱼 → 5L/桶 或 4L/桶
- AE营养多纯香菜籽油 → 金龙鱼 → 1.8L/瓶
- 优质东北大米 → 金龙鱼 → 5KG/袋
- 寒地东北大米 → 福临门 → 5KG/袋
- 优选泰香米 → 香纳兰 → 5KG/袋

### 4.2 项目级字段

最终版说明区明确：

- 综合报价
- 报价含税含运
- 年度预估量仅供参考，以采购平台实际下单数量为准
- 评标规则：未税总价最低拟中选（排名）
- 本次计划定 1 家，具体签约数量以开标约谈为准
- 付款周期 120 个自然日
- 对账期 5 天
- 开票期 10 天
- 结算期 105 天
- 配送范围：重庆市、贵州省
- 合作期限：1 年

## 5. 最终版仍需检查的潜在问题

“最终版”并不意味着所有隐藏维度都已完全展开。

后续 `招标价格对比表.xlsx` 中，同一物料/规格被明确拆成“重庆市”“贵州省”两行，而最终版需求清单只在项目说明中写了配送范围，没有给每一物料行明确城市字段。

因此 Skill 应继续检查：

> 当同 SKU 重复出现且项目覆盖多个区域时，是否需要增加 `quantity_by_region` 或行级 `delivery_region`，以保证供方按区域报价、数量与物流条件一致。

## 6. 版本数量变化规则

后续价格对比表中的部分数量与最终需求清单不同。

Skill 必须：

1. 报告“版本间数量发生变化”；
2. 列出差异；
3. 要求采购员确认当前有效版本；
4. 不得自动用后续表覆盖标准需求。

## 7. 预期 Skill 行为

### 输入：初版需求清单

预期输出至少应包括：

- 识别 18 条物料；
- 不把空白报价列算作需求缺失；
- 识别品牌/规格不足；
- 识别 6 组重复物料名称；
- 识别“同名 + 不同参考价”可能隐藏规格差异；
- 询问配送区域；
- 询问报价口径；
- 询问账期；
- 询问合作期限；
- 询问评标价格口径与拟中选供方数量；
- 在 P0 未解决前，不进入供方匹配。

### 输入：最终版需求清单

预期输出至少应包括：

- 正确提取品牌与规格；
- 正确提取重庆/贵州配送范围；
- 正确提取 120 天付款周期；
- 正确提取未税总价最低的评标口径；
- 正确提取拟中选 1 家；
- 仍对重复 SKU 触发行级区域拆分检查；
- 将含税单价、未税单价、税率等识别为供方响应字段；
- 只有在采购员确认区域拆分等 P0 问题后，才输出 `requirement_status: confirmed`。
