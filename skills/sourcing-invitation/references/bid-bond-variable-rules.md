# 投标保证金变量规则

## 1. 模板变量

企业原版《招标意向征集登记表模板.xlsx》的 `Sheet1!N3` 不再保留固定金额，必须使用：

`{{投标保证金金额}}`

生成项目登记表时，将该变量替换为本次项目计算出的投标保证金金额。

## 2. 计算口径

基础金额必须来自当前项目可追溯的 `采购清单预估总金额`，不得使用供应商尚未填写的报价列，也不得沿用历史模板的固定金额。

计算公式：

`投标保证金原始值 = 采购清单预估总金额 × 1%`

`投标保证金金额 = CEILING(投标保证金原始值, 1000)`

即：向上取整到 1,000 元的整数倍。

示例：

- 预估总金额 523,673.81 元 → 1% = 5,236.7381 元 → 保证金 = 6,000 元；
- 预估总金额 1,234,567 元 → 1% = 12,345.67 元 → 保证金 = 13,000 元；
- 预估总金额 80,000 元 → 1% = 800 元 → 保证金 = 1,000 元。

## 3. 数据来源优先级

1. 当前最终需求/采购清单中已经人工确认的预估总金额；
2. 上游 `historical-procurement-analysis` / `material-requirement-analysis` 已形成且可追溯的项目预估总金额；
3. 采购员明确确认的本项目预估总金额。

不得：

- 从供应商报价空白列计算；
- 使用历史模板金额；
- 自行猜测预估单价或总金额。

## 4. 缺失处理

如果无法获得可追溯的采购清单预估总金额：

- 标记 `missing_procurement_estimated_total_amount`；
- 不得把 `{{投标保证金金额}}` 静默替换为 0、6000 或其他默认值；
- 提示采购员补充/确认采购清单预估总金额；
- 03 登记表不得标记为 ready。

## 5. N3 完整性检查

生成后的 `Sheet1!N3` 必须：

- 不再包含 `{{投标保证金金额}}` 占位符；
- 金额等于 `CEILING(采购清单预估总金额 × 1%, 1000)`；
- 其余原模板文字与样式保持不变。
