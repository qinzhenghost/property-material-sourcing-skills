# Category and Region Matching Rules

## 1. 官方三级分类结构

当前《物资类供应商三级分类表.xlsx》字段：

`一级 | 二级 | 三级 | 备注`

例如：

`物资类 | 食品饮品 | 米面粮油 | 食用油`

`物资类 | 食品饮品 | 米面粮油 | 大米`

其中：

- 一级：物资类
- 二级：食品饮品
- 三级：米面粮油
- 备注：更细的物料/商品参考

供方名录对应字段：

- 二级类型
- 三级类型
- 合作业务

因此供方匹配优先到“三级类型”，不要要求供方库必须存在备注层级。

## 2. 多值字段

官方供方库存在：

- `电器百货/文体宣传/食品饮品`
- `休闲食品,米面粮油`
- `米面粮油、生活小家电`

匹配前允许对分隔符进行 token 化：

- `/`
- `,`
- `，`
- `、`
- `;`
- `；`

必须保留原始字段。

## 3. 品类匹配等级

### exact

二级 + 三级明确包含需求分类。

### compatible

三级明确包含需求分类，但二级为多品类组合或字段表达不完全一致。

### partial

只匹配二级大类，缺三级能力证据；或合作业务间接相关但不足以证明完整供应。

### no_match

官方字段与需求分类明确不一致。

### unknown

字段缺失或无法解释。

## 4. 不能使用公司名称作为能力证明

错误：

> “重庆东强粮油食品有限公司”名称包含粮油，因此匹配。

正确：

> 官方二级类型 = 食品饮品；
> 官方三级类型 = 米面粮油；
> 因此品类匹配。

公司名称只能帮助人工阅读，不能作为 Gate evidence。

## 5. 区域名称规范化

允许：

- 重庆 → 重庆市
- 贵州 → 贵州省

以及其他明确的一一行政区名称标准化。

不允许：

- 重庆 → 西南区域
- 区域级供方 → 自动认为覆盖周边省份
- 注册地址重庆 → 自动认为供货重庆
- 全国性公司名称/规模 → 自动推断全国配送

## 6. 区域匹配

需求：重庆市、贵州省

供方官方覆盖：重庆

结果：

`partial`

而不是 `full`。

如果当前只拿到重庆区域名录：

- 必须说明数据源本身可能是局部供方库；
- 不得通过公网补贵州供应商；
- 应请求贵州/区域级官方供方库，或人工决定分区域处理。

## 7. 资质

资质只在以下情况作为 Hard Gate：

- 需求明确要求；
- 企业正式规则明确要求。

官方供方库中已有资质字段时可以用来：

- 提示存在资质；
- 检查有效期字段；
- 触发人工核验。

不得凭 AI 法律常识自行创建门槛。
