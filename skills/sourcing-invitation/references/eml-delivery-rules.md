# 单一 BCC EML 交付规则

`sourcing-invitation` 只生成一封 `.eml` 草稿，所有人工确认且邮箱已确认的供方统一放入 `Bcc`。

固定交付物：

```text
{{项目名称}}-邀标邮件.eml
{{项目名称}}-最终需求清单.xlsx
{{项目名称}}-招标意向征集登记表.xlsx
```

规则：

- `Bcc`：已确认邀标且邮箱来源可追溯的供方；
- `To`：不得填写供方邮箱，仅可使用采购方明确提供的本方地址；
- `Cc`：仅内部确认地址；
- 缺邮箱/冲突邮箱不得猜测；
- EML 不嵌入两个 Excel，`attachments_embedded = false`；
- 正文只引用两个附件文件名；
- 两个 Excel 独立交付并由采购员实际发送前添加；
- 不自动发送邮件；
- 被排除、hold、待补证供方不得进入 BCC。
