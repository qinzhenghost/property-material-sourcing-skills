# sourcing-strategy V3 模板深度回归测试

使用 `sourcing-strategy` 基于企业 V3《物资采购方案报告模板》生成 `strategy-data.yaml` 与采购方案报告 DOCX。

本测试全部为脱敏 Mock 数据。

## 项目事实

项目名称：重庆示例物业物资年度采购
采购方式：邀请招标
采购周期：12个月
配送范围：重庆主城区 + 两个区县项目

## 历史支出事实

- 历史有效期：2025-07-01 至 2026-06-30
- 有效订单：200单
- 有效含税采购金额：1,000,000元
- 平均订单金额：5,000元
- 业务单元A：700,000元，占70%
- 业务单元B：200,000元，占20%
- 业务单元C：100,000元，占10%
- SKU-A：300,000元，占30%，数量2,500，历史均价120元
- SKU-B：220,000元，占22%，数量2,000，历史均价110元
- SKU-C：160,000元，占16%，数量4,000，历史均价40元
- SKU-D：120,000元，占12%，数量1,000，历史均价120元
- SKU-E：80,000元，占8%，数量2,000，历史均价40元
- 其余SKU：120,000元，占12%

### 订单金额段

- 3,000元以下：80单，占40%
- 3,000-5,000元：50单，占25%
- 5,000-10,000元：45单，占22.5%
- 10,000元以上：25单，占12.5%

## 内部供应市场信号

- 官方供方库品类匹配：15家
- 明确覆盖目标区域：9家
- 实际邀约：7家
- 明确回复：6家
- 采购员最终确认短名单：5家
- 2家反馈区县小额订单需要最低配送金额
- 1家对120天账期需要内部审批

## 当前采购规则

- 最终短名单已人工确认
- 定标规则及中标家数由采购员确认，测试不得自行发明
- 正式免运/最低配送金额尚未确认

## 市场研究

若运行环境可联网，针对“重庆 + 当前示例物业物资品类”检索至少3个相互独立、优先近12个月的公开来源。公开市场企业不得加入邀标池。

## Test objective

重点验证最新模板：

1. 支出分析 `1整体 / 2军种(业务单元) / 3SKU / 4免运额度` 四块全部处理；
2. 当地供应市场行情 `市场情况 / 成本构成情况` 两块全部处理；
3. 内容超出模板原单元格时扩展表格/行高/跨页，不通过删减分析维持原页数；
4. 报告不得残留 X/XX/X%，不得把供应商名称串入章节标题；
5. 内容深度不足不得标记 ready_for_approval。
